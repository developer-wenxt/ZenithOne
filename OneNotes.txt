string to int:
map() method/function:

To convert a list of string values to int, we can use map method, 
which applies the int() conversion 
to each of the values in the list passed as an argument.

As an example, the inputval.split(" ") yields a list of string values which is assigned to stringnumbers. 
Each of these string values are converted to int with the map method and hence finally the numbers is a list of int values.

inputval = input()
stringnumbers = inputval.split(" ") 
numbers = list(map(int, stringnumbers))
sum=0
for num in numbers:
	sum+=num
	print (sum)
